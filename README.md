Meridian Run — fly a low-poly jet through ten glowing rings over a river valley, then bring her home on the runway. Chase and cockpit cameras, a live HUD (altitude, speed, heading, fuel, throttle, attitude), procedural engine and wind sound, and a seeded valley that is the same every flight.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, just static files.
